# Minecraft Summer Vacation Research Workshop Landing Page

This is a landing page for a Minecraft summer vacation research workshop for children.

## Overview

This landing page is designed to promote a special workshop where children can complete their summer vacation research projects using the popular game Minecraft. The workshop aims to foster programming-like thinking and creativity while having fun.

## Features

-   **Hero Section:** An attractive headline that appeals to children and parents.
-   **Workshop Details:** Explains the workshop's purpose and target audience.
-   **Curriculum:** Outlines the workshop's content, which includes programming, building with Redstone, observing ecosystems, and more.
-   **Benefits:** Lists the key advantages of participating in the workshop.
-   **Testimonials:** Features feedback from past participants to build trust and credibility.
-   **Registration Form:** A simple form for users to sign up for the workshop.

## Technologies Used

-   HTML
-   CSS
-   JavaScript

## How to View Locally

1.  Clone this repository to your local machine.
2.  Open the `index.html` file in your web browser.
