ワークショップ概要

夏休みの自由研究、何にしようか迷っていませんか？このワークショップでは、大人気ゲーム「マインクラフト」の世界を舞台に、プログラミングや建築、実験を通して、自分だけのオリジナル作品を制作します。

専門の講師が丁寧にサポートするので、マインクラフト初心者でも、プログラミング未経験でも大丈夫！楽しみながら、論理的思考力や問題解決能力を身につけ、夏休みの自由研究を楽しく完成させましょう。

ワークショップ内容

プログラミングで自動建築

Code ConnectionやMakeCodeを使って、コマンドブロックで自動建築に挑戦！

レッドストーン回路でからくり装置

レッドストーンの仕組みを学び、自動ドアやエレベーターなどを作ってみよう！

バイオームの生態系を観察

様々なバイオームを探索し、動植物の生態系を観察・記録してレポート作成。

オリジナル建築物制作

自由な発想で、未来都市や秘密基地など、巨大な建築物を設計・建設。

自由研究発表会

制作した作品や研究成果を発表し、みんなで共有します。
